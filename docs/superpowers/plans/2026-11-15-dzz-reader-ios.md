# DzzReader iOS App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A personal iOS app that bundles the 2,982-text 大正藏 corpus and reads plain-text books with a shelf, themes, fonts, bookmarks, progress and chapter jumping, native selection/copy/share, and runtime txt import.

**Architecture:** A local Swift package `DzzCore` holds all Foundation-only logic (toc parsing, chapter indexing, line classification, decoding, progress maths) and is tested with `swift test` on macOS. The `DzzReader` app target (SwiftUI shell, SwiftData persistence, one `UITextView`/TextKit 2 reading surface loaded one chapter at a time) depends on it. The corpus is copied into the bundle by an rsync build phase.

**Tech Stack:** Swift 6.4, SwiftUI, UIKit (`UITextView`, TextKit 2), SwiftData, Swift Testing, XcodeGen 2.46, Xcode 27.2, iOS 26.0 deployment target.

**Spec:** `docs/superpowers/specs/2026-11-15-dzz-reader-ios-design.md`

## Global Constraints

- iOS 26.0 deployment target; Swift 6 language mode; iPhone + iPad device family, iPhone layout only.
- Project lives at `/Users/jerry/projects/buddhism-kb/DzzReader/`; generated by XcodeGen from `project.yml`; the generated `DzzReader.xcodeproj` is committed too.
- Bundle id `com.jerryfleming.dzzreader`, display name `大藏经`.
- Corpus copied from `../dzz` by a Run Script phase into `Books/` inside the bundle; `.git`, `README.md`, `TODO` excluded. Never an Xcode folder reference.
- All offsets are UTF-16 (`NSString`/`NSRange`) units.
- Chapter mark prefix is `第0章 ` (regex `^第\d+章\s*`). Marks cover 卷 headings (marked twice: open + close, closing line may add a parenthetical), 品 sub-headings (marked once) and false marks on body paragraphs (normalised text over 30 chars after removing parentheticals). Chapters are 卷; 品 are `Section`s inside a chapter; false marks and closing lines are plain paragraphs. Chapters over 120,000 UTF-16 units are split into parts.
- Persisted offsets (progress, bookmarks) are SOURCE-text UTF-16 offsets; the rendered text drops the mark prefixes and an offset map converts both ways.
- UI copy is Simplified Chinese: 大藏经, 导入, 搜索经名或经号, 最近阅读, 导入的书, 目录, 下一卷, 全书完, 卷首, 添加书签, 跟随系统.
- Themes: light, sepia (#F4ECD8 / #5B4636), dark (#1C1C1E / #D0D0D0), black (#000000 / #BBBBBB), system. Font size 14–40 default 20; line spacing 1.2–2.2 default 1.6; margin 8–40 default 20.
- Build/test commands: `cd DzzReader/DzzCore && swift test` for core; `xcodebuild -project DzzReader/DzzReader.xcodeproj -scheme DzzReader -destination 'platform=iOS Simulator,name=iPhone 17 Pro Max' build` for the app.
- Git: commit into the `buddhism-kb` repo (root `/Users/jerry/projects/buddhism-kb`); `dzz/` is already ignored there. Do not stage anything under `dzz/`.

## Review Focus

Inputs the spec implies but no requirement names; each gets a test in its owning task.

1. A marked file whose 卷 heading text differs between its opening and closing line (trailing full-width space, or a parenthetical only on the closing line, as in 中阿含经). Expected: still one chapter, not two. → Task 3 (`collapsesPairsIgnoringWhitespaceAndParentheticals`).
2. A toc line where the 〖朝代 译者〗 cell is missing, a `0310#N` sub-entry line, or a `(第1-200卷)` 卷数. Expected: entry parsed with `author == nil` / sub-entry skipped / `juanCount == 200`, no crash. → Task 2 (`parsesEntryWithoutAuthor`, `skipsSubEntries`, `parsesRangeJuanCount`).
3. An imported txt with Windows CRLF line endings. Expected: no stray `\r` in displayed text, chapter headings still detected. → Task 5 (`decodeNormalisesCRLF`).
4. Restoring progress whose stored `characterOffset` exceeds the chapter length (file replaced by a shorter one). Expected: clamp to end, no crash. → Task 5 (`locateClampsOutOfRange`) and Task 8 (restore clamps).
5. The 0-byte bundled file and a file whose body has no paragraphs. Expected: opens, shows the title line and `全书完`, progress 100%. → Task 3 (`emptyTextYieldsSingleEmptyChapter`) and Task 8 manual check.
